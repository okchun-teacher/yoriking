# 요리킹 조리킹

초등학교 5·6학년 실과 **식생활** 단원을 담은 도트 요리 타이쿤 웹게임이에요.
실과책을 펴다가 픽셀 마을로 빨려 들어간 학생 요리사가 곰 사장님의 간식집을 맡아, 깨끗하고 안전하게 요리하며 최고의 가게 「요리킹 조리킹」을 만들어 가요.

## 플레이

- 브라우저에서 `yoriking.html`을 열면 바로 시작해요. 설치는 필요 없어요.
- 조작: `WASD`·방향키 이동 · `Space` 행동·연타 · 칼질은 방향키+`Space` 리듬 · `Shift·Q·R` 스킬 · `X` 내려놓기 · `1∼6` 주문표 · `P` 멈춤 · `H` 도움말 · `M` 소리 · `B` 음악
- 기록은 브라우저(localStorage)에 저장돼요.

## 담긴 실과 내용

- 조리 전 준비: 앞치마·머릿수건, 손 씻기, 재료 고르기와 씻기
- 안전한 조리: 칼질(고양이 손), 가열 조리, 전자레인지와 주방용 장갑
- 균형 잡힌 식사: 식품군과 식품 구성 자전거, 간식 고르기
- 식사 예절, 음식물 쓰레기 분리배출, 지역 식품과 식품 이동 거리(푸드 마일리지)
